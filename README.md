# Customer Churn Prediction

## Overview
This project predicts customer churn using machine learning and customer account data.

## Tools Used
- Python
- Pandas
- Scikit-learn

## Features Used
- Tenure
- Monthly Charges
- Contract Type
- Internet Service

## Project Steps
1. Data loading and preprocessing
2. Encoding categorical variables
3. Splitting training and testing data
4. Training a machine learning model
5. Evaluating model performance

## Business Value
This project shows how machine learning can help businesses identify customers who may leave, so they can improve retention strategies.
